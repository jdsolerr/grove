# Política de seguridad

## Reportar una vulnerabilidad
**No abras un issue público.** Usa el reporte privado de GitHub:
pestaña **Security → Report a vulnerability** de este repositorio.

Incluye pasos para reproducirlo, versión de Grove y sistema operativo. Responderé en cuanto pueda; es un proyecto personal y no hay plazo garantizado.

## Alcance
- Fuga o robo del token de GitHub, ejecución de código no esperada, lectura o escritura fuera del repositorio abierto.
- Dependencias con CVE explotables en Grove.

## Fuera de alcance
- Forks y versiones no oficiales.
- Ataques que requieren acceso local previo a tu cuenta de usuario.

## Versiones con soporte
Solo la última versión publicada en [Releases](../../releases/latest).
