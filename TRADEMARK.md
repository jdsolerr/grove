# Nombre y logo

El **código** de Grove es MIT (ver [`LICENSE`](LICENSE)); la licencia no concede derechos sobre el nombre ni el logo: puedes forkearlo, traducirlo, modificarlo y redistribuirlo, también comercialmente.

El **nombre «Grove»** (para este cliente Git) y el **logo** (`assets/grove-logo.png`) son de jdsolerr y **no** están incluidos en la licencia MIT.

## Qué puedes hacer
- Decir que tu proyecto «es un fork de Grove» o «está basado en Grove», con un enlace a este repositorio.
- Usar el nombre y el logo para referirte al proyecto original (por ejemplo, en un artículo o una reseña).

## Qué no
- Distribuir un fork o una traducción con el nombre «Grove» o con este logo como si fuera el programa original u oficial.
- Dar a entender que tu versión está respaldada, firmada o mantenida por el autor.
- Usar el client ID de la OAuth App oficial de Grove: registra la tuya (ver README).

## Si distribuyes un fork
1. Cámbiale el nombre (un nombre propio que no se confunda con «Grove»).
2. Sustituye el logo y el identificador de la app (`dev.grove.app` en `app/src-tauri/tauri.conf.json`).
3. Conserva `LICENSE` y `THIRD_PARTY_LICENSES`.
4. Indica claramente que es una versión no oficial.

Grove es un proyecto independiente y no está afiliado ni respaldado por GitHub, Inc. «GitHub» es marca de GitHub, Inc.
